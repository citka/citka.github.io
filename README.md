# V-Convert

เว็บแปลงไฟล์วิดีโอที่ผู้ใช้อัปโหลดเองเป็น MP4 หรือ MP3 ด้วย FFmpeg

## ฟีเจอร์
- MP4 / MOV / MKV / WEBM / AVI / M4V เป็นไฟล์ต้นทาง
- ส่งออก MP4 (720p, 1080p หรือคงขนาดเดิม) หรือ MP3 192 kbps
- Dark premium UI พร้อมพื้นหลังไล่เฉดสีและละอองดาวเคลื่อนไหว
- จำกัดไฟล์อัปโหลด 500 MB และเวลาประมวลผล 15 นาที
- ไฟล์ชั่วคราวถูกลบหลังส่งไฟล์กลับ (หากการเชื่อมต่อปิดตามปกติ)

## รันบนเครื่องตัวเอง

ต้องติดตั้ง Python 3.11+ และ FFmpeg ก่อน

1. ติดตั้ง FFmpeg
   - Windows: ดาวน์โหลดจาก https://ffmpeg.org/download.html และเพิ่มโฟลเดอร์ `bin` ใน PATH
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt update && sudo apt install ffmpeg`
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. สร้าง environment และติดตั้งแพ็กเกจ

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

เปิด http://127.0.0.1:5000

## เผยแพร่ออนไลน์ด้วย Render

1. สร้างบัญชี GitHub และ Render
2. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ใน Render เลือก **New + → Blueprint** แล้วเชื่อม repository
4. Render จะอ่าน `render.yaml` และสร้างบริการจาก Dockerfile
5. เมื่อ deploy เสร็จ จะได้ URL แบบ `https://ชื่อบริการ.onrender.com`

หมายเหตุ: `render.yaml` ตั้งแผน Starter ไว้เพราะการแปลงวิดีโอต้องใช้ CPU/RAM และพื้นที่ชั่วคราว ตรวจสอบราคา/ข้อจำกัดของ Render ก่อนยืนยันบริการ แผนฟรีอาจไม่เหมาะกับไฟล์ใหญ่หรือการใช้งานต่อเนื่อง

## ข้อควรทราบก่อนเปิดสาธารณะ
- เวอร์ชันเริ่มต้นนี้ไม่มีระบบบัญชีผู้ใช้หรือโควตาต่อผู้ใช้ หากเปิด URL สาธารณะ คนอื่นก็ใช้ทรัพยากรเซิร์ฟเวอร์ได้
- จำกัดไฟล์ 500 MB และเวลาประมวลผล 15 นาที แต่ควรเพิ่ม rate limit, authentication และระบบคิวก่อนเปิดให้คนทั่วไปใช้
- อย่าใส่รหัสผ่านหรือ API key ลงใน GitHub
- ใช้แปลงเฉพาะไฟล์ที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ใช้งาน
- ไฟล์อัปโหลดถูกเก็บชั่วคราวเพื่อแปลงเท่านั้น แต่ควรหลีกเลี่ยงไฟล์ส่วนตัว/ข้อมูลอ่อนไหวบนบริการโฮสต์สาธารณะ
